# FortaFlow — Portfolio Preview

A lightweight public showcase of **FortaFlow**, an AI-assisted trading research concept.

This repository is intentionally separate from the private product repository. It contains only a static presentation intended for portfolio and job-application review.

## What this preview shows
- A high-level product direction for turning hypotheses into structured research.
- An illustrative interface for reviewing scenarios and assumptions.
- Product principles focused on clarity, comparison, and careful interpretation.

## Scope and safety
- The site is a single static `index.html`; no build step or dependencies are required.
- All dashboard values and charts are fictional examples. They are not live market data, backtest results, or evidence of returns.
- No sign-in, trading connections, API calls, database, analytics, tracking, or third-party assets are included.
- This repository excludes the private application's source, internal plans, integration logic, infrastructure configuration, schemas, and production data.
- This is a concept presentation, not a trading tool, investment recommendation, or financial advice.

## Preview locally
Open `index.html` in any modern browser. GitHub Pages can also serve it as a static site.
